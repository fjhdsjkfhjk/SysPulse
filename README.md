# SysPulse

一个 **纯本地运行** 的 macOS 菜单栏系统监控小工具。

所有指标都通过系统公开 API 在本机内存中读取，**不联网、不埋点、不申请任何权限**，代码开源可审计。

## 功能

- **菜单栏**实时显示（可切换）：
  - CPU 占用率
  - 网速（↓ 下载 / ↑ 上传，上下两行、固定宽度不跳动）
  - 或两者
- **图形化仪表盘**（点击菜单栏图标弹出）：
  - **CPU**：折线图 + 用户/系统占用
  - **内存 / 磁盘**：条形图 + 已用/总量
  - **电池**：条形图 + 状态、最大容量、循环次数
  - **网络**：下载/上传双折线 + 实时速率 + WiFi 名称
  - **GPU**：型号
- 刷新间隔可调（2 / 5 / 10 / 30 秒）

## 设计原则：纯本地运行

| 行为 | SysPulse |
|---|---|
| 网络请求 | **无**（不发起任何连接） |
| 遥测 / 埋点 | **无**（不集成任何分析 SDK） |
| 崩溃上报 | **无** |
| 设备标识 | 不收集、不上报 |
| 权限申请 | **无**（不需要辅助功能 / 屏幕录制） |
| 数据落盘 | 仅两项设置（菜单栏模式、刷新间隔）存 `UserDefaults` |

> 这是本项目最重要的设计约束：监控数据只在你本机内存中存在，程序本身没有任何外发通道。

## 构建

需要 macOS 13+ 和 Xcode 命令行工具（`xcode-select --install`）。

```bash
cd SysPulse
./build.sh
open SysPulse.app
```

产物 `SysPulse.app` 使用本地临时签名，仅建议自己构建使用。

## 使用

- 菜单栏显示所选指标，点击弹出图形化仪表盘
- 仪表盘底部切换「菜单栏显示」模式与「刷新间隔」
- 「退出 SysPulse」退出

## 诊断模式（验证读取）

```bash
SYSPULSE_DIAG=1 ./.build/release/SysPulse
```

会打印一次采样结果并退出，方便确认各项指标。

## 隐私说明

- 所有数据通过系统公开 API 在**本机内存**中读取，程序**不发起任何网络连接**。
- 不读取、不上传任何个人文件、键盘输入、剪贴板内容。
- 不采集设备唯一标识（无 InstallId / UUID 上报）。
- 除「菜单栏模式」和「刷新间隔」两项设置外，无任何落盘。

## 已知限制

- 无 WiFi 连接时（如使用手机热点 / USB 共享）`WiFi` 显示「未连接」，属正常。
- 台式机（无电池）电池项显示「无」。
- 温度 / 风扇转速未实现（macOS 读取 SMC 需要私有 API 或提权，为避免权限和风险，暂不提供）。
